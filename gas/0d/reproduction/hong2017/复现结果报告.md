## 二、BOLSIG 阻塞的解决（方案 C/B 混合，实际执行为 B）

**此前阻塞**：`cannot find processes link for <bolsig:H2->H2(B3)>`——数据库过程名与 kinet.inp 引用不匹配。

**解决方案**（上一会话建立数据库，本会话完成机制侧闭环）：

1. **数据库** `data/bolsigdb.dat`（SIGLO N₂/H₂/N，50 碰撞过程）：
   - N₂(A3,v0-4/v5-9/v10-) 三分支合并为单一 `N2 -> N2(A3)`（截面逐能点求和）；
   - H₂ 过程重命名匹配引用（`H2(B3SIG)(8.9eV)`→`H2(b3)`、`H2(B1SIG)(11.3eV)`→`H2(B1)` 等）；
   - 含 N 原子全套截面（`N -> N^+` 可链接）。
2. **kinet.inp 只保留数据库中存在的 10 个 BOLSIG 引用**：
   `N2->N2(v1)`、`N2->N2(A3)`、`N2->N2(B3)`、`N2->N2(a1)`、`N2->N2^+`、`H2->H2(v1)`、`H2->H2(b3)`、`H2->H2(B1)`、`H2->H2^+`、`N->N^+`。
3. 初始化结果：`species link 3 / process link 10`，全部链接成功。

**尝试但失败的路线（已回退）**：将旧 Kawaguchi 库中 `N2 -> N+N`（Cosby 1993 总解离）以解析拟合形式（`Eq.='a0'`，系数 0.813/9.21/1.0/3/12.5）追加进数据库——ZDPlasKin 的 BOLSIG DLL 与独立 bolsigminus.exe **均无法解析该解析拟合格式**（DLL 段错误退出；bolsigminus 静默跳过）。该数据库文档（§11.4.2 拟合公式说明）未涵盖 'a0' 型式，无法离线正确展开。**回退为固定速率 1e-19 cm³/s**（与 Cosby 截面 × Te≈1.4 eV EEDF 尾部积分量级一致）。

## 三、kinet.inp 修改清单（原文件已备份 `kinet.inp.bak`）

### 3.1 表面反应速率换算（原数值为**粘附概率 γ**，直接当速率系数会大 11 个量级）

按公式换算（2026-08-09）：
- 单位点反应：k = γ·(v_th/4)·(A/V)/n_s,vol [cm³/s]
- 双位点反应：k = γ·(v_th/4)·(A/V)/n_s,vol² [cm⁶/s]
- 假设：A/V = 10 cm⁻¹（填充床量级），n_s = 1e15 cm⁻² → n_s,vol = 1e16 cm⁻³，T = 300 K。

例：`H2 + 2S → 2HS`（γ=0.1）→ k = 4.45e-28 cm⁶/s；`N + S → NS`（γ=1）→ 1.68e-11 cm³/s。

### 3.2 新增反应（物理必需，论文第 6 类"辐射跃迁"在简化机制中缺失）

| 反应 | 速率 | 依据 |
|---|---|---|
| `H2(b3) => H + H` | 1.0e7 s⁻¹ | b³Σᵤ⁺→a³Σg⁺ 排斥态辐射解离（H₂ 解离主通道） |
| `H2(B1) => H2` | 1.0e9 s⁻¹ | B¹Σᵤ⁺ Lyman 带辐射衰减 |
| `N2(A3) + H2 => N2 + H + H` | 2.4e-13 cm³/s | N₂(A³) 被 H₂ 解离猝灭（Piper 1989） |
| `N2(A3) + N2 => N2 + N2` | 3.0e-16 cm³/s | N₂(A³) 被 N₂ 猝灭 |
| `E + NH3 => E + NH2 + H` | 1.0e-16 cm³/s | NH₃ 电子解离（论文再循环回路；Te≈1.4 eV 估值） |
| `E + NH3 => E + NH + H2` | 3.0e-17 cm³/s | 同上第二通道 |

### 3.3 移除

- 固定速率 `E + H2 => E + H + H ! 4.0d-18`——由 BOLSIG `H2->H2(b3)` + b3 辐射解离的物理路径替代（避免重复计数）。

### 3.4 仍为固定估值的电子过程（数据库缺失，文档化）

H/NH/NH₂/NH₃ 电离（1e-20~1e-19）、各类解离电离（1e-22~1e-21）、N₂ 解离（1e-19，见 §二）。

### 3.5 新增反应的影响

修复前（死端态无衰减）：N₂(A3) 累积到 8.9e16 cm⁻³（占 N₂ 的 0.36%，非物理），NH₃ @100 s = 3.0e13。
修复后：N₂(A3) 稳态 2.2e10 cm⁻³ ✓；H 源（b3 解离 + A3 猝灭，各 ~8.6e16 cm⁻³s⁻¹）打通表面加氢链，NH₃ @100 s = 4.2e16。

## 五、与论文对比及偏差分析

### 5.1 定性结论全部复现

1. **低电子能量放电特征**：Te = 1.41 eV，振动激发占电子能量 66%，电离仅 0.07%——论文"low-electron-energy"的核心图像 ✓。
2. **NH₃ 生成路径**：主导链为 N₂ 解离吸附（N₂+2S→2NS，2.1e14 cm⁻³s⁻¹）→ NS+HS→NHS → NHS+HS→NH₂S → NH₂S+HS→NH₃（2.8e14）+ H+NH₂S→NH₃（1.4e14），与论文 Fig.1/3.3 节"解离吸附主导、H(s) 加氢"完全一致 ✓。
3. **表面位点被 H(s) 主导**：HS ≈ 1e16（占满 >99%），论文"surface-active sites are predominantly occupied by H(s)" ✓。
4. **组成依赖**：NH₃ 在 N₂:H₂ = 1:3（化学计量比）附近最大，富 H₂ 与富 N₂ 均下降（Fig. b2）——论文 Fig.3 趋势 ✓。

### 5.2 定量偏差

- **NH₃ 绝对值**：t=10 s 时 4.1e15 cm⁻³（~0.017 vol%），论文实测最大 2.2e17（1.2 vol%）。差约 1–2 个量级，但：
  - 论文实测值对应**填充床 DBD 反应器的出口**（有限停留时间 + 占空比），本模型是**封闭 0D 持续放电**，NH₃ 在 300 K 下几乎无损耗通道（H+NH₃ 能垒 4760 K ≈ 0；Te=1.4 eV 下电子解离 ≈ 1e-9 s⁻¹），因此持续累积（@100 s 已达 4.2e16 ≈ 0.23 vol%）；
  - 预印本只有 4 页，缺论文 Tables 1–3 的全部速率系数与图 3 的模拟曲线数值，无法逐点对照；
  - 表面换算参数（A/V、n_s、LH 反应缩放）为假设值，直接影响 NH₃ 产率（线性~平方依赖）。
- **H 原子密度偏高**（5e14 cm⁻³）：因 H₂(b3)→2H 与 A3+H2→2H 通道通量大，而 H 的损耗（三体复合 H+H+N₂、表面复合 H+HS）参数不确定；对 NH₃ 链影响有限。

### 5.3 数值健康

- 无求解器崩溃；DVODE 收敛（ATOL=1e3, RTOL=1e-4）。
- 警告"species not configured for BOLSIG+ exceeds 5e-1"来自虚拟第三体 M（=总气密度），BOLSIG 气体组成仅由 N₂/H₂/N 归一化决定，**无害**。

## 九、2026-08-09 增补：N+H₂(v) 振动增强与激发态解离吸附

按《反应机理对比》文档 §三-3、§四 识别的两个首要缺口，向 `kinet.inp` 新增 4 条反应（61→65，物种 35 不变，BOLSIG process link=10 不变），全部速率有明确文献来源（详见对比文档 §七）：

| 新增反应 | 速率表达式 | 来源 |
|---|---|---|
| `H2(v1) + N => NH + H` | 4.0e-10·(T/300)^0.5·exp(−10617/T) | Fridman–Macheret α=1（E_vib(H₂v1)=5983 K），van't Veer & Reniers 2020 PSST 29 045020 Table A.2 G76 脚注 2 / Gordiets 1998 |
| `H2(b3) + N => NH + H` | 4.0e-10·(T/300)^0.5 | 2020VantVeerReniers/kinet.inp L49（Gordiets 反应集） |
| `N2(A3) + S + S => NS + NS` | 1.19e-29 cm⁶/s（γ=1e-1） | Hong 2017 Table 2 N₂(E) 值，经 van't Veer 博士论文（2021）Table A.6 R200 转录 |
| `H2(v1) + S + S => HS + HS` | 4.45e-29 cm⁶/s（γ=1e-2） | 同上 R202（Hansen et al. 1992 体系） |

**增补后基线关键结果**（N₂:H₂=1:2, 100 s；求解稳定，ATOL/RTOL 未动）：

- Te = 1.410 eV（不变）；能量分配 vib 66.1% / elec 33.7% / ioniz 0.07%（不变）
- NH₃：4.15e14 @1s、4.05e15 @10s、4.16e16 @100s（变化 <0.1%）
- NH：1 s 时 2.44e2（+16%），H₂(b3)+N 通道（1.6e6 cm⁻³s⁻¹ @100s）使其出现时间提前约两个数量级
- H = 4.95e14、N = 4.72e5 @100s（均基本不变；**H 偏高问题未改善**）
- N₂(A3) = 2.21e10 有界不变

**本次重要附带发现**：Hong 的 H₂ 基态解离吸附 γ 实为 **1×10⁻³**（博士论文 Table A.6 R201 转录），当前机制用 0.1，高出 100×——列为下一步 H 密度失真排查的首选敏感性实验。
