## 三、论文 §3.3 建议的 8 步简化机理：逐条核对

论文基于模拟结果给出的 NH₃ 生成主链（Fig. 4 示意图）：

| # | 论文反应 | 当前机制 | 状态 |
|---|---|---|---|
| 1 | H₂ + 2surf(s) → 2H(s)（解离吸附） | `H2 + S + S => HS + HS ! 4.45d-28`（γ=0.1 换算） | ✓ |
| 2 | E + N₂ → E + 2N（电子解离） | `E + N2 => E + N + N ! 1.0d-19`（固定估值） | ✓ 速率是估值 |
| 3 | **N + H₂(v) → H + NH** | **只有基态版** `H2 + N => NH + H ! 4.0d-10*(T/300)^0.5*exp(-16600/T)` | ⚠️ **重要缺口**：基态反应能垒 16600 K，300 K 下速率 ~1e-34 cm³/s，实际不反应。论文明确"NH 自由基由 N 原子与**振动激发** H₂ 反应生成"。当前缺 `N + H2(v1) → NH + H` 的振动增强速率（Hansen et al. 计算） |
| 4 | NH + H(s) → NH₂(s) | `NH + HS => NH2S ! 2.44d-13` | ✓ |
| 5 | NH₂(s) + H(s) → NH₃ | `NH2S + HS => NH3 + S + S ! 5.04d-14` | ✓ |
| 6 | E + NH₃ → E + NH₂ + H（再循环） | `E + NH3 => E + NH2 + H ! 1.0d-16`（复现时补加） | ✓ |
| 7 | NH₂ + H(s) → NH₃ | `H + NH2S => NH3 + S ! 5.04d-13` | ✓ |
| 8 | E + NH₃ → E + NH₂ + H | 同 #6 | ✓ |

**8 步中 7 步已覆盖**，第 3 步的振动态版本是当前机制与论文最重要的单点差异。补偿效应：当前模型中 N 源主要靠 `N2+2S→2NS` 解离吸附（2.1e14 cm⁻³s⁻¹），NS 经表面加氢链同样能到 NH₃，所以 NH₃ 量级仍复现正确——但 **NH 自由基的气相生成路径与论文不同**，H/NH 密度会因此失真（当前 H 密度偏高与此有关）。

## 六、总结：当前机制与论文的对应度

**定量可比的部分**（结论已验证一致）：
- 电子能量分配、Te、低能放电特征 ✓
- 解离吸附主导 N(s)/H(s) 生成、H(s) 占满位点 ✓
- 表面加氢链 → NH₃ 的主路径 ✓
- NH₃ 随 N₂:H₂ 比的变化趋势 ✓

**与论文有实质差异的 4 个点**（按重要性排序）：

1. **缺 `N + H₂(v) → NH + H`**：论文的 NH 主生成通道；影响气相 NH/H 分布，对 NH₃ 总量影响被表面路径部分补偿。
2. **缺振动/电子激发态的解离吸附增强**（Hansen）：论文自称的"首次引入"创新点；可能低估 N(s) 生成速率。
3. **表面换算参数 A/V、n_s 为假设值**：NH₃ 绝对产率的系统性不确定来源。
4. **缺 V-V、解离复合、H⁻ 化学、多级振动激发**：本条件下次要，扩展研究时必需。

**补齐路径**：①和②需要完整版论文 Table 1/2 的数值或 Hansen 1992 (*Surf. Sci.* 264, 225) 原文；③需要论文实验段落的反应器几何（α-Al₂O₃ 填充床尺寸）；④可参照 van't Veer & Reniers (2020) 的扩展机制（其 kinet.inp 已在 `Reproduction/2020VantVeerReniers/` 就绪，65 物种 158 反应含 v=1–24 全套 V-V/V-T）。

## 七、2026-08-09 增补：补齐 §三-3 与 §四 的两个首要缺口

本次在 `kinet.inp` 中新增 4 条反应（61 → 65 反应，物种不变仍为 35；增补前母版备份为 `kinet.inp.bak2`）。所有速率均可追溯到实际检索到的来源。

### 7.1 缺口 1：N + H₂(v) → NH + H（振动增强，已补）

检索结果：van't Veer & Reniers 2020 (*Plasma Sources Sci. Technol.* **29**, 045020) 附录 A（本地文件 `Reproduction/2020VantVeerReniers/vantveer_reniers_2020_psst_extracted.txt` 第 971–975、1057–1060、1221–1225 行）Table A.2 反应 G76 给出基态表达式 `4.0×10⁻¹⁰(Tg/300)^0.5·exp(−16600/Tg)`，脚注 2 明确："The reaction only occurs for the vibrational levels [66]. The reported rate coefficient is scaled according to the Fridmann–Macheret alpha-model [79] with **α = 1**"，其中 [66] = Gordiets et al. 1998 *PSST* **7**, 363（即 Hong 论文 ref [10]），[79] = Fridman《Plasma Chemistry》。Fridman–Macheret α 模型（定义见 arXiv:2105.03118 式 (5)）：表观能垒 Ea_eff = Ea − α·E_vib。H₂(v=1) 振动能 = 4158.5 cm⁻¹ = 0.5157 eV = **5983 K**（由 H₂ 光谱常数 ω_e=4401.2 cm⁻¹、ω_ex_e=121.3 cm⁻¹ 计算），故 Ea_eff = 16600 − 5983 = **10617 K**。

新增反应（kinet.inp）：

```
H2(v1) + N => NH + H ! 4.0d-10 * (Tgas/300.0d0)**0.5d0 * exp(-10617.0d0/Tgas)
```

同时补入电子激发态类似通道，来自 `Reproduction/2020VantVeerReniers/kinet.inp` 第 49 行（同为 Gordiets 反应集，能垒全消）：

```
H2(b3) + N => NH + H ! 4.0d-10 * (Tgas/300.0d0)**0.5d0
```

注：我们的机制只含 H₂(v1) 一个振动态；v≥2 未含，故未加。α=1、300 K 下 v1 通道 k ≈ 1.6×10⁻²⁵ cm³/s，较基态（~4×10⁻³⁴）增强 ~4×10⁸ 倍，但绝对值仍小——见 §7.4 速率对比。

### 7.3 附带发现（重要，未改动）

博士论文 Table A.6 显示 Hong 的 **H₂ 基态解离吸附 γ = 1×10⁻³**（R201），而当前机制（及本项目两个 van't Veer 复现的 kinet.inp）用 **γ = 0.1** —— 高出 100×。为保持基线可比性，本次**未改动**基态反应；但该差异可能是 H(s)/H 分配失真的系统性来源，建议下一步单独做 γ(H₂ dads) 1e-3 vs 1e-1 的敏感性对比。此外 van't Veer 复现 kinet.inp 中 `N2(A3)+S+S` 用 γ=1e-2（未增强），与博士论文转录的 Hong 值 γ=1e-1 不一致，本次采用博士论文值。
