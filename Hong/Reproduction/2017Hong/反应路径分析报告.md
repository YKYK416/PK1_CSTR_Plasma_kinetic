# Hong 2017 复现 · NH₃ 合成反应路径分析报告

日期：2026-08-09 · 工况：N₂:H₂ = 1:2，1 atm，300 K，E/N = 45.1 Td，nₑ = 1.17×10⁸ cm⁻³（固定）
对象：65 反应重构版（build/） vs 完整 515 反应版（build_full/，Shao Fe 表面）

## 1. 方法

1. **多时刻速率快照**：两个主程序（`main_hong.F90` / `main_full.F90`，均保留 `.bak` 备份）在时间循环内增加快照逻辑，于 t = 1e-6、1e-4、1e-2、0.1、1、10、100 s（取首个 ≥ 名义时刻的模拟步）将全部反应速率以长表写入 `hong_rates_t_N2H2_1_2.csv` / `full_rates_t_N2H2_1_2.csv`。两个 build 均通过 `rebuild.sh main` 重编译 + 冒烟测试，基线终值与改动前完全一致（NH₃：4.16e16 / 5.23e15）。
2. **化学计量解析**（`pathway_analysis.py`）：解析反应式（保护 `^+` 离子后缀、剥离前置系数如 `2SURF`、归一化 bolsig 标签 `N2(A3,V0-4)→N2(A3)`；特例 `bolsig:N2->N2(SUM)` 映射为 e+N₂→e+2N，它是 LXCat 集总解离截面）。对每个物种按净化学计量数 × 速率排名产/耗通道，取 top-5 及占比。
3. **通道分类**：NH₃ 生成分为气相三体 / 气相两体 / 表面 ER（气相种+吸附种）/ 表面 LH（全吸附种）；N(s)、H(s) 来源分为分子解离吸附 vs 原子直接吸附；NH 来源分为 N+H₂(v) / N+H₂(电子态) / N+H₂ 基态 / NH₃ 解离 / NH₂ 转化。
4. **时间积分**：7 个快照点上对数-对数分段幂律解析积分（对幂律段精确），得 1e-6→100 s 各通道累计 NH₃ 产量。⚠️ 只有 7 个时刻点，对快速变化段是粗积分，仅用于通道排序与占比量级。
5. 所有数字均直接读自上述 CSV（`pathway_analysis.json` 为机器可读存档），未做任何外推虚构。

### 3.2 早期 → 晚期切换

- **完整 515 反应**：气相三体全程 ≥95.6%，无"气相→表面"类别切换（Fe 表面全程冻结）；但**主导子通道发生切换**：t ≤ 10 s 为 `NH+H₂+H₂→NH₃`（66.5%→32.9% 递减），**切换发生在 10–100 s 之间**，t = 100 s 时 `H+NH₂+H₂→NH₃`（39.2%）居首。物理解读：早期 NH 充足（来自 N+H₂*），NH 与 H₂ 三体直接合成 NH₃；随 NH₃ 积累，NH₃ 解离（e+NH₃→NH₂+H）提供大量 NH₂，晚期转为 H+NH₂ 三体主导——这正是论文 Fig.1(a) "NH₂ 主要来自 NH₃ 解离，再回到 NH₃"的循环结构，只是回程载体从论文的表面 H(s) 换成了气相三体。
- **65 反应重构**：无类别切换，表面 LH 从 1e-6 s 起主导；ER 份额在 ~0.01 s 建立到 33% 后稳定。论文 Fig.1(b) 的早期气相三体阶段**复现不出**——因该版气相 NHx 密度太低（NH₃ 三体通道最高仅 0.1%）。

## 4. 关键物种来源分解（t = 100 s）

### 4.1 NH 来源 —— 与论文"N+H₂(v)"叙述的定量对照

**论文 §3.1/Fig.4**：NH 由 N + H₂(v)（振动激发氢）生成。**机理编码的实际情况（300 K）**：

| 通道 | 速率常数表达式 | 300 K 有效 k |
|---|---|---|
| N + H₂(v1–v3) → NH + H | 4e-10·exp(−16600/T + 0.3·5800·v/T) | **e^(−49.5)～e^(−37.9)，冻结** |
| N + H₂(B3Σ/B1Σ/C3Π/A3Σ/RYDBERG) → NH + H | 4e-10（无障碍） | 4e-10 |

- **完整 515**：NH 生成的 **86.3% 来自 N + H₂ 电子激发态**（`N+H₂(B3SIG)` 68.4%，5.3e14；B1SIG 7.6%；C3PI 6.7%），**振动通道仅 0.1%**（H₂(v1) 密度仅 5.7e12 且 k 冻结）；其余 NH₂ 转化 7.9%、NH₃ 解离 5.7%。
- **65 重构**：早期（≤0.01 s）`H₂(B3)+N` 占 81–100%；**晚期转为循环通道主导**——`H+NH₂→NH+H₂` 61.0%（2.3e8）+ `e+NH₃→NH+H₂` 38.6%，N+H₂(v1) 全程 ~0（1.9e-4）。

**结论**：论文所说的"激发态 H₂ + N → NH"的**机制精神（等离子体激发态驱动）成立**，但在该机理 300 K 的编码下，载体是**电子激发态（以 b³Σᵤ⁺ 为主）而非振动态**——N+H₂(v≤3) 通道被 Arrhenius 势垒数学上排除，与振动密度高低无关（即使 65 版 H₂(v1) 密度 2.3e15 也不起作用）。这是本复现对论文叙述的一个重要定量修正。

### 4.2 N 原子来源（区分毛生成与净源）

- **完整 515**：毛生成 top1 是循环通道 `H+NH→N+H₂`（85.5%，6.8e14）；**净源为电子解离 `e+N₂→e+2N`（bolsig N₂ SUM 集总截面，1.15e14 @100s，占 14.5%）**。
- **65 重构**：同样 `H+NH→N+H₂` 63.3%（3.3e8）+ `e+N₂→e+2N` 36.7%（1.9e8）。
- 两版 N 密度差 6 个量级（7.9e11 vs 4.7e5），根源：完整版 e+N₂ 解离速率大 ~600 倍（17 物种 57 碰撞 BOLSIG 组的振动分辨/集总截面使有效解离系数大得多），且 N+NH₂→N₂ 消去通道配比不同。

### 4.3 N(s) / H(s) 来源与表面占据（论文 Fig.2 对照）

- **两版均验证论文 Fig.2**：N(s)、H(s) **几乎全部来自分子解离吸附**（完整版原子直接吸附严格为 0；65 版 @100 s 原子 H 吸附 6.5e13 vs 解离 3.1e17，占 0.02%；原子 N 吸附占 0.009%），与"解离吸附主导、非常压等离子体典型"的论文结论一致。
- **H(s) 占据主导** ✓：65 版 HS = 1.0e16 vs NS = 5.1e11、空位 S = 4.7e12；完整版 HSURF = 2.87e17（位点全被 H 占满）、NSURF = 3.2e13、空位 7.4e9。
- 但完整版表面链在 NH(s) 处断流：NSURF+HSURF→NHSURF 速率仅 6.1e2，NHSURF+HSURF→NH₂SURF 4.5e-20——**DFT 熵势垒（活化能 1.13/1.23/1.21 eV + 扩散 0.2 eV）在 300 K 下逐级冻结**，NH₂(s) 密度 4.5e-18，LH 步骤（论文 step 5）速率 1.5e-31。65 版用热速率常数（5.04e-14），LH 链全通。

## 6. 时间积分累计（1e-6 → 100 s，分段幂律粗积分）

**完整 515**：累计 NH₃ 生成 ≈ 2.0e16 cm⁻³，**气相三体 96.7%**（H+NH₂+H₂ 37.0% + NH+H₂+H₂ 27.2% + H+NH₂+N₂ 18.7% + NH+H₂+N₂ 13.7%），气相两体 3.3%（含 e+NH₄⁺→NH₃+H 3.3%），表面 ≈ 0。终态 NH₃ = 5.2e15 ⇒ 约 74% 被再解离消耗，气相合成-解离准平衡。

**65 重构**：累计 ≈ 4.2e16 cm⁻³，**表面 LH 66.8% + 表面 ER 33.1%**，气相三体 0.03%。终态 NH₃ = 4.2e16，与累计生成几乎相等 ⇒ 该版 NH₃ 几乎无气相消耗，产出即积累。

## 7. 诚实的 caveats

1. **表面不一致**：完整版是 Shao 的 Fe 表面 + DFT 熵势垒（其基准为 400 K、原设计工况 Tgas=550 K），不是论文的 α-Al₂O₃。300 K 下 Fe 表面链数学上冻结，因此完整版无法复现论文 Fig.1(a) 的表面回程——这不是 bug，是表面材料与温度约定的直接后果。要做论文级定量复现，需换回氧化铝黏附系数表面集（thesis Table A.6 fallback 仍未启用）。
2. **两套几何/位密度约定不同**（Surf=2.87e17 vs S=1e16 + A/V=10），表面通量绝对值不可直接互比。
3. **Tₑ 不同**（完整 0.85 eV vs 65 版 1.41 eV，源于 BOLSIG 碰撞组差异），激发态密度与 e-impact 速率差因此放大。
4. 速率快照仅 7 个时刻，时间积分是对数网格分段幂律近似；通道占比排序稳健，累计值的绝对精度有限（尤其跨越快速变化段时）。
5. 完整版 `bolsig:H2->H2(RYDBERG_SUM)` 标签被两个不同反应共用，分析中按速率求和聚合（不影响 NH₃ 路径结论）。
6. `H+NH→N+H₂`、`H+NH₂→NH+H₂` 等属 N↔NH↔NH₂ 循环交换，报告中已区分毛生成与净源，避免把循环通量误读为源强。
