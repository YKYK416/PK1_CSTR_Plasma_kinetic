# Hong 2017 完整反应集直接运行报告（第三阶段）

日期：2026-08-09 · 工况：N₂:H₂ = 1:2，1 atm，300 K，E/N = 45.1 Td，nₑ = 1.17×10⁸ cm⁻³（固定）

## 1. 机制出处链（重要）

本阶段不再走"重构近似"，而是**直接运行 Hong 完整反应集**。来源链：

- **GitHub `wwwccttoo/DFT-microkinetic`** → `Model_SA_Const_Entropy_base/`，对应论文 Shao & Mesbah, *JACS Au* 2024。
- 该代码**直接改编自 Hong & Murphy 提供的原始代码**：气相动力学 = Hong 2017 原始机制（kinet.inp，48 物种、515 反应、41 个 BOLSIG 引用）。
- **⚠️ 关键 caveat：表面部分不是 Hong 的氧化铝表面。** 原 C17 表面模块被 Shao 改成了 **Fe 表面 + DFT 熵势垒（Const-Entropy 方法）**，46 个表面反应，配套 4 个 DAT 数据文件（`ENTROPY_INFO_BASIS.DAT`、`ENTROPY_PARA_IN.DAT`、`REACTION_E_BASIS.DAT`、`REACTION_E_IN.DAT`）。

**分支选择说明**：我们走的是主线——Shao 的熵机制离线完整跑通（4 个 DAT 文件齐全，预处理器与求解器均无错误），因此**没有**启用 fallback 方案（学位论文 Table A.6 的黏附系数表面集）。报告中所有"完整 515 反应"结果均含 Fe 表面而非氧化铝表面，与 Hong 论文做定量对比时必须牢记这一点。

## 2. 为跑通所做的代码改动（最小侵入）

| # | 改动 | 原因 |
|---|------|------|
| ① | `kinet.inp` 中两个超长熵参数 READ 语句（272/400 字符）拆成 `&` 续行 | ZDPlasKin 预处理器单行截断上限 256 字符；其余 >200 字符行均 <256，安全。这是 kinet.inp 的**唯一**改动（原件备份为 `kinet.inp.orig`） |
| ② | `zdplaskin_m.F90` 中 `ZDPlasKin_reac_rates` 的 use 行补 `density` | 完整机制的速率子程序需要访问 `density`，预处理器默认模板未导出。已固化为 `rebuild.sh` 中的 sed 补丁 |
| ③ | 编译加 `-ffree-line-length-none` | 预处理器生成的长行 |
| ④ | 求解器容差 ATOL=1d0 / RTOL=1d-4 | Const_E.F90 原用 ATOL=1e-1；本运行未遇到求解器收敛问题，未再调整 |

预处理与编译结果：**515 reactions、41 BOLSIG refs、708 行 Fortran，预处理器通过**；`rebuild.sh` 全量重建 + smoke test（1 s）验证通过。`build/`（65 反应基线）未动过。

### 结果解读

1. **Tₑ 差异（0.85 vs 1.41 eV）是物理的，不是错误。** 完整 BOLSIG 碰撞组覆盖 17 物种 57 个碰撞过程，含振动分辨 N₂ 截面、电子态与超弹性去激发通道；在相同 E/N=45.1 Td 下，更多非弹性损失通道 → 更低的平衡电子温度。65 重构版用的是 3 物种 50 碰撞的合并表，振动损失被人为压缩，Tₑ 偏高。
2. **NH/NH₂ 高 5–6 个量级**：完整机制中 N + H₂(v) → NH + H 等振动促进链式通道以全截面运作（且 Tₑ 虽低但振动/电子态化学更完整），印证了我们 Gap1 增补时的判断——"论文的 NH 主通道是 N+H₂(v)"。65 重构版只补了 v1/b3 两个通道，NH 仍被低估。
3. **NH₃ 低约 8 倍**：方向与"完整机制气相自由基化学更活跃"一致，但注意表面是 Fe（催化活性与氧化铝不同）且表面位密度约定完全不同（2.87×10¹⁷ vs 1×10¹⁶），NH₃ 的定量差异**不能**直接归因于气相机制。
4. N 原子高 6 个量级：完整机制含 N(²D)/N(²P) 猝灭循环与完整的 N₂⁺/N₄⁺ 离子化学，基态 N 的源项强得多。
5. 能量分配：完整版非弹性功率占比 97.7%（vs 重构 99.9%），电子温度低 → 弹性碰撞份额上升，自洽。

## 5. 剩余缺口与注意事项

- **表面化学不匹配**：Fe 表面 + DFT 熵势垒 ≠ Hong 论文的氧化铝表面。要复现论文定量结果，需把表面模块换回 Hong 原始的黏附系数/氧化铝参数（本报告未做）。
- **Tₑ 差异来源**：完整 BOLSIG 碰撞组（17 物种 57 碰撞，含振动分辨截面与超弹性）与 65 版合并表（3 物种 50 碰撞）本质不同，两者 Tₑ 不可直接对齐比较绝对速率。
- **温度基准**：Shao 的熵势垒基准密度硬编码在 400 K；我们在 300 K 运行，熵修正项严格来说不在其拟合基准点。
- **nₑ 固定**：两版均为固定 nₑ = 1.17×10⁸，未解电中性/电荷守恒自洽演化。
- H₂(B3SIG)、H₂(RYDBERG_SUM)、N₂(A₃) 等电子态全程有界（max 分别 ~1.8×10¹²、~2×10⁹、2.5×10¹¹），无数值爆炸。
