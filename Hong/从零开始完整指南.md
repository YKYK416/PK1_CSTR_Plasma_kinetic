## 第 2 章：核心概念——四个文件一条流水线

```
kinet.inp          bolsigdb.dat         main.F90
(反应机理+物种)     (电子碰撞截面)         (物理条件主程序)
     │                  │                     │
     └──► preprocessor.exe ──► zdplaskin_m.F90 ◄┘
              (语法检查+代码生成)      │
                          gfortran + dvode_f90_m.F90 + bolsig_x86_64_g.lib
                                   │
                              main.exe ──运行──► output.csv / rates.csv
                                   │
                          Python 后处理 ──► 图 + 报告
```

**关键理解**：
- ZDPlasKin 把"机理"与"求解器"分离。`preprocessor.exe` 读取 kinet.inp，把物种表、反应表、BOLSIG 接口**翻译成一个 Fortran 模块** `zdplaskin_m.F90`。
- 主程序通过 `use ZDPlasKin` 调用它，DVODE 负责刚性 ODE 积分，BOLSIG+ 库在线求解电子玻尔兹曼方程给出电子碰撞反应速率。
- **改 N₂比例/时长 → 只需命令行传参；改 E/N/温度 → 重编译主程序（几秒）；改机理 → 重跑 preprocessor + 全量编译。**

## 第 3 章：获取与制作截面数据（bolsigdb.dat）

### 3.1 数据来源

1. **LXCat**（https://nl.lxcat.net）：注册 → 选数据库（SIGLO / Phelps / Biagi / IST-Lisbon）→ 选物种与过程 → 下载文本。⚠️ 本项目遇到过网站返回 HTML 而非数据的问题；备选是找已有模型的发行文件（如 Shao 2024 仓库自带的 173 KB bolsigdb.dat，本项目 `build_full/` 在用）。
2. **别人模型自带的 bolsigdb.dat**：最省事且与机理引用天然匹配。

### 3.2 文件格式（每个碰撞过程一个块）

```
EXCITATION
N2 -> N2(A3)          ← 过程名：kinet.inp 的 BOLSIG 引用要精确匹配它
6.17                   ← 阈值能 (eV)；弹性过程此行为质量比
SPECIES: e + N2
PROCESS: e + N2 -> e + N2(A3), Excitation
COMMENT: ...
UPDATED: ...
0.000000E+00  0.000000E+00     ← 能量(eV) | 截面(m²)，两列
...（几十到几百行数据点）
```

块类型：`ELASTIC` / `EFFECTIVE` / `EXCITATION` / `IONIZATION` / `ATTACHMENT`（大小写敏感）。

### 3.3 合成自己的数据库

把需要的过程块**按文本拼接**到一个文件即可。本项目的 `merge_bolsigdb.py` 和 `方案3_截面库UQ/db_uq/db_tools.py` 是可复用的解析/合并/重命名工具。

### 3.4 截面数据的 5 个坑（全部实测）

1. **EFFECTIVE vs ELASTIC**：两项近似求解器需要 EFFECTIVE（总动量转移）；只有 ELASTIC 时低 E/N 平均能量可偏差 20–25%（方案3 实测 0.231 eV 的 Te 差）。
2. **缺失某气体的动量转移截面会让 Te 整体漂移**（方案3 首因：缺 H₂ 动量转移 → Te 差 0.74 eV）。
3. **'a0' 解析拟合格式（如 Cosby N₂ 解离）ZDPlasKin 的 BOLSIG DLL 解析不了**（段错误），只能手工列表化或用固定速率。
4. **过程名必须与机理引用逐字符一致**（见第 4 章），只改第二行 `A->B`、不动阈值和数据。
5. **振动分辨 vs 集总**：同一激发态可能分多个振动分支（N2(A3,v0-4/v5-9/v10-)），合并 = 逐能点截面求和。

## 第 4 章：编写 kinet.inp（机理文件）

### 4.1 四段式结构

```fortran
ELEMENTS
E N H S M          ! 元素表：E=电子（必须），S/M 是本项目自定义的虚拟元素
END

SPECIES
E N2 H2 N H NH NH2 NH3 M
N2(v1) N2(v2)              ! 振动态：圆括号
N2(A3) N2(B3) N2(a1)       ! 电子激发态
N2^+ N^+ H2^+              ! 离子：^+
S NS HS NHS NH2S           ! 表面物种（自定义命名，如 Shao 版用 Surf/HSurf）
END

BOLSIG
N2                         ! 只列基础气体物种！不要列 N2(v1) 等
H2
set dbfile bolsigdb.dat
END

REACTIONS
反应式 ! 速率表达式 或 ! Bolsig 数据库过程名
END
```

### 4.2 速率表达式语法（Fortran 风格）

```
N + NH => H + N2                          ! 5.0d-11                          常数 [cm³/s]
H + NH2 => H2 + NH                        ! 6.6d-11 * exp(-1840.0d0/Tgas)    Arrhenius
N + N + M => N2 + M                       ! 1.38d-33 * exp(502.978d0/Tgas)   三体 [cm⁶/s]
E + N2 => E + N2(A3)                      ! Bolsig N2->N2(A3)                BOLSIG 在线计算
```

- `Tgas` 是内置变量（气体温度 K）
- 也可嵌入 Fortran 行（以 `$` 开头）做能级分辨的内嵌速率计算（完整机制的 V-T/V-V 就是这样实现的，约 700 行）

### 4.3 七条铁律（全部来自实际报错）

1. **元素守恒**：每个反应左右两边各元素（含 E）原子数相等。电离：`E + N2 => E + E + N2^+`（产物 2 个电子）。
2. **BOLSIG 引用名 = bolsigdb.dat 过程名**，逐字符匹配；否则初始化报 `cannot find processes link for <bolsig:XXX>`。
3. **每个激发态必须有衰减出路**（辐射/猝灭/解离），否则非物理累积（实测 N₂(A3) 曾堆到基态的 0.36%）。
4. **表面反应**：论文给的粘附概率 γ 不是速率系数！换算：
   - 单位点 `k = γ·(v_th/4)·(A/V)/n_s,vol` [cm³/s]；双位点 `k = γ·(v_th/4)·(A/V)/n_s,vol²` [cm⁶/s]
   - v_th=√(8kT/πm)，A/V=表面体积比，n_s,vol=位点体密度
5. **BOLSIG 段只列基础气体**；DENSITY 行也只接受基础物种。
6. **M（第三体）必须同时是元素和物种**，并在主程序里锁定为总密度。
7. **数据库没有的电子过程**：写固定速率 + 注释说明量级估计依据（诚实标注）。

### 4.4 验证

```bash
printf '.\n\n' | ./preprocessor.exe kinet.inp
# 输出物种数/反应数/BOLSIG引用数；WARNING（未使用物种）可容忍，ERROR 必须清零
```

> preprocessor 有**两次交互**（输出文件名 + 回车退出），用 `printf '.\n\n' |` 自动应答。

## 第 5 章：编译

```bash
export PATH="/f/Softwares/Ming64/mingw64/bin:$PATH"

# 编译（模块有依赖顺序：dvode → zdplaskin_m → main）
gfortran -O2 -c dvode_f90_m.F90 zdplaskin_m.F90 main.F90 -static-libgfortran -static-libgcc

# 链接（必须用带 _g 的库变体）
gfortran -O2 -o main.exe main.o zdplaskin_m.o dvode_f90_m.o \
  -L. -lbolsig_x86_64_g -static-libgfortran -static-libgcc
```

| 要点 | 原因 |
|---|---|
| `-static-libgfortran -static-libgcc` | 不加则 gfortran 16 运行时 0xC0000005 崩溃；编译和链接阶段都要带 |
| `bolsig_x86_64_g.lib`（带 `_g`） | 8 个库变体中本项目验证唯一可用；对应 dll 必须与 exe 同目录 |
| `libquadmath-0.dll` 与 exe 同目录 | 否则运行报缺库 |
| 只改主程序时 | 只需重编译 main.o 再链接，模块 .o 可复用 |

**自检**：`./main.exe <短模拟>` 应在秒级打印结果；初始化行应显示 `species link N / process link M` 全部链接成功。

## 第 6 章：编写主程序

### 6.1 最小骨架（固定条件）

```fortran
program main
  use ZDPlasKin
  implicit none
  double precision :: time, dtime, ntot

  call ZDPlasKin_init()
  call ZDPlasKin_set_config(ATOL=1.0d3, RTOL=1.0d-4)

  ntot = 2.446d19   ! 1 atm, 300 K 的总气体密度 [cm-3]
  call ZDPlasKin_set_conditions(GAS_TEMPERATURE=300.0d0, REDUCED_FIELD=45.1d0)
  call ZDPlasKin_set_density('N2', 0.333d0*ntot)
  call ZDPlasKin_set_density('H2', 0.667d0*ntot)
  call ZDPlasKin_set_density('M',  ntot, ldens_const=.true.)   ! 第三体锁定
  call ZDPlasKin_set_density('E',  1.17d8, ldens_const=.true.) ! 固定电子密度

  time = 0.d0; dtime = 1.d-9
  do while (time .lt. 100.d0)
    call ZDPlasKin_timestep(time, dtime)
    time = time + dtime
    dtime = min(dtime*10.d0**0.1d0, 10.d0)   ! 对数步进
  end do
end program
```

完整可编译示例见 `build/main_hong.F90`（121 行，含 CSV 输出、命令行参数、反应速率导出）。

### 6.2 三个进阶技巧（本项目实际使用）

1. **恒压变温**：`ntot = 2.446d19 × (300/Tgas)`——温度扫描时千万别固定 ntot（方案1 的关键物理）。
2. **方波 E/N(t) 脉冲**：在时间循环内按相位切换 `ZDPlasKin_set_conditions(REDUCED_FIELD=...)`；切换点强制小步长防刚性崩溃；E/N=0 可能让 BOLSIG 出错，用 0.1 Td 地板。完整实现见 `方案2_脉冲能效地图/build_pulse/main_pulse.F90`。
3. **多时刻速率快照**：循环内在 t = 1e-6/1e-4/…/100 s 调 `ZDPlasKin_get_rates(REACTION_RATES=rates)` 写长表（time, reaction_sign, rate），供路径分析用。实现见两个主程序的 `.bak` 对照。

### 6.3 常用 API（手册：`1.ZDPlasKin/ZDPlasKin_manual.txt`）

| 调用 | 用途 |
|---|---|
| `ZDPlasKin_get_conditions(ELEC_TEMPERATURE=, REDUCED_FIELD=, ELEC_POWER_N=...)` | 取 Te、E/N、电子功率（弹/非弹分量） |
| `ZDPlasKin_get_density('NH3', n)` | 取某物种密度 |
| `ZDPlasKin_get_rates(REACTION_RATES=rates)` | 取全部反应速率（`reaction_sign(i)` 给反应式字符串） |
| `species_max / reactions_max / species_name / density(:)` | 模块内置数组与计数 |

## 第 10 章：故障排查 FAQ（本项目全部实测坑）

| 症状 | 原因 | 解法 |
|---|---|---|
| gfortran 调用无反应无产物 | 不在 PATH | `export PATH="/f/Softwares/Ming64/mingw64/bin:$PATH"` |
| 编译过了但运行 0xC0000005 | gfortran 16 运行时动态库 | 加 `-static-libgfortran -static-libgcc` |
| 链接失败 undefined reference | 用了 `bolsig.lib` | 改用 `bolsig_x86_64_g.lib` |
| 运行报缺 libquadmath-0.dll | 运行库未随行 | 从 mingw64/bin 复制到 exe 同目录 |
| `cannot find processes link for <bolsig:XXX>` | 过程名不匹配 | 对照 bolsigdb.dat 第二行逐字符改 |
| preprocessor 卡在等待输入 | 两次交互未应答 | `printf '.\n\n' \| ./preprocessor.exe kinet.inp` |
| 激发态密度持续累积 | 死端物种 | 补辐射/猝灭衰减通道 |
| NH₃ 差 11 个量级 | 把粘附概率当速率系数 | 按 4.3-4 公式换算 |
| BOLSIG 段报错 | 列了激发态/振动态 | 只列基础气体物种 |
| E/N=0 时崩溃/异常 | BOLSIG 低场限制 | 用 0.1 Td 地板 |
| "species not configured for BOLSIG+ exceeds 5e-1" | 虚拟物种 M 未配进 BOLSIG 气体 | **无害警告**，忽略 |
| DVODE 高温/高场失败 | 刚性 | 放宽容差（登记备案）、切换点强制小步长 |
| LXCat 下载得到 HTML | 网站接口问题 | 用模型自带库 / 换镜像 / 稍后重试 |
| 'a0' 拟合截面段错误 | DLL 不支持解析拟合格式 | 手工列表化或固定速率 |
