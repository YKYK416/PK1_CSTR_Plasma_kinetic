# 研究方案 2：常压 N₂-H₂ DBD 脉冲放电的气相能效地图

> 选题框架文档（直觉泵 #1 系统化 + #5 新坐标轴）
> 日期：2026-08-22 · 约束：纯气相 0D ZDPlasKin

## 第 1 页：核心想法

### 标题
**频率 × 占空比 × E/N 三维参数空间的能效地图：脉冲 DBD 合成氨的气相化学优化边界在哪？**

### 科学问题
Hong 2017 Table 3 给出两个诱人的孤点预测：频率 500 Hz→1 kHz 使 NH₃ 密度提升 6.4 倍；1 kHz/40% 占空比优于 500 Hz/100% 占空比 2.4 倍（且能耗更低）。Zeng et al. 2023 做了脉冲参数优化，但所有现有工作都是**稀疏点采样**——没有人系统回答：

- 能效最优区在 (f, duty, E/N) 空间的什么位置？是孤峰还是高原？
- "余辉化学"（afterglow 中自由基继续反应）占 NH₃ 总产量的份额随占空比如何变化？
- 是否存在气相化学本征的占空比下限（低于它余辉不足以利用累积的激发态）？

### 方案
主程序改造为**方波 E/N(t) 驱动**（放电相 E/N_on + 余辉相 E/N ≈ 0），对每个工况积分 20–100 个周期至**周期稳态**（判据：相邻周期 NH₃ 增量 <0.1%），然后系统扫描：

| 参数 | 范围 | 采样 |
|---|---|---|
| 频率 f | 0.5 – 100 kHz | 对数 7 点 |
| 占空比 d | 10% – 100% | 7 点 |
| 放电相 E/N_on | 30 – 150 Td | 5 点 |
| **合计** | 245 工况 ×（秒级/工况） | 总机时 < 1 小时 |

**输出坐标**（直觉泵 #5：换坐标轴）：
- 纵轴 1：**单位能耗 NH₃ 产量**（g/kWh 或 molec/eV）——工程目标函数
- 纵轴 2：**余辉贡献份额**（余辉相 NH₃ 增量 / 全周期增量）——机理解释变量
- 分析：能效等高线图 + 沿论文 Table 3 四个工况点的**验证锚点**

### 创新点
1. **从孤点到地图**：Table 3 的 6.4×/2.4× 是 4 个点的结论；245 工况的连续地图能判断这些点是否落在最优区、最优区有多大
2. **余辉份额作为机理坐标**：把"为什么脉冲更好"从定性叙事变成定量分解（放电相产自由基 vs 余辉相产 NH₃）
3. **内置验证**：先用 Table 3 条件复现 6.4× 和 2.4× 两个数，验证了才扫全空间——论文可信度前置建立

### 重要性
- 脉冲供电是等离子体合成氨**能效提升的主流工程路线**，参数空间地图可直接指导反应器设计
- 气相能效地图是所有后续表面/催化研究的**基线参照**（表面只能在此之上增减）
- 与候选 1 联动的潜力：脉冲加热 → 局部 T 升高 → 振动通道开关（两个项目可合并成一篇大文章的气相部分）

### 直觉泵来源
#1（把 4 个孤点变成系统化扫描）+ #5（余辉份额作为新坐标轴）

## 第 2 页：批判性分析

### 固定 vs 浮动参数

| 固定 | 浮动 |
|---|---|
| 机理：515 反应完整版气相（去表面） | f、d、E/N_on（扫描变量） |
| 波形：方波（先做方波，正弦作为附录抽查） | 周期数（收敛判据自动控制） |
| 压力 1 atm、N₂:H₂ = 1:2、T = 300 K | 余辉相 E/N_off（0 或 5 Td 敏感性） |
| nₑ 在放电相 = 1.17e8 cm⁻³ 固定 | nₑ 余辉衰减模型（固定 vs 指数衰减） |

### 关键假设与风险

| 假设 | 类型 | 风险(1-5) | 缓解 |
|---|---|---|---|
| 气相模型（无表面）的**相对趋势**对脉冲优化仍有意义 | 物理 | 3 | 明确声明：绝对产率不代表填充床实验，地图的价值在最优区**位置**与相对倍数；Table 3 验证锚点提供实证支撑 |
| 方波 E/N 近似 DBD 微放电的时间包络 | 物理 | 3 | E/N_off 敏感性分析；文献中微放电脉宽 ns 级 vs 我们的 AC 包络 μs 级，讨论节如实区分两个时间尺度 |
| 周期稳态在 100 周期内可达 | 数值 | 2 | 收敛判据自动延长；NH₃ 是累积量，用周期增量而非绝对值判断 |
| 脉冲内刚性（E/N 突变时 DVODE 步长崩溃） | 数值 | 2 | E/N 切换点强制小步长重启；已在主程序框架内验证过 45.1 Td 固定工况的稳定性 |
| nₑ 固定在物理上忽略余辉电子衰减 | 物理 | 3 | 对比实验：固定 nₑ vs 余辉指数衰减（τ ~ 1–10 μs）两版，报告差异 |

### 避开的陷阱
- **跟风陷阱**（把工具应用到新系统）⚠️：Zeng 2023 已做脉冲优化——差异化必须在**地图完整性 + 余辉份额分解 + Table 3 定量验证**三点上写清楚，引言中明确对比
- **零风险** ✗：本项目风险集中在"气相趋势 vs 实验可比性"，已通过定位声明管理

### 替代路径
- **Plan B**：若 245 工况全扫描中部分高温/高 E/N 点求解失败 → 自适应网格（先粗扫 3×3×3，在最优区加密）
- **Plan C**：若周期稳态收敛太慢 → 改用"单脉冲响应函数 + 叠加"近似，论文角度转为方法论

### 文献背景
- Hong et al. 2017 Table 3（验证锚点：6.4×、2.4×）
- Zeng et al. 2023 *ACS Sustain. Chem. Eng.*（直接竞争/对照对象）
- van't Veer et al. 2020 *JPCC* 124, 22871（微放电与余辉物理）
- 竞争程度：**中**（Zeng 在先，但地图化 + 余辉分解的角度未见）
- 我们的优势：完整机制 + 已参数化的主程序 + Table 3 的精确条件可从预印本提取

1. Table 3 第 (1)(2) 行：500 Hz/100% vs 1 kHz/100%，能否复现 ~6.4× NH₃ 提升
