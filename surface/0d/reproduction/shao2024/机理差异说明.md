# Shao 2024 与 Hong 2017 完整机制的差异

比较对象：

- Shao：`dft_microkinetic_windows_case/kinet_source.txt`；
- Hong：`Reproduction/2017Hong/方案1_振动开关温度/build_tscan/kinet.inp`。

按 `SPECIES`、`REACTIONS` 和 BOLSIG+ 注释统计：

| 指标 | Shao 2024 DFT–微观动力学 | Hong 2017 完整机制 | 差值 |
| --- | ---: | ---: | ---: |
| 物种数 | 48 | 48 | 0 |
| 反应数 | 468 | 422 | +46 |
| BOLSIG+ 反应数 | 41 | 41 | 0 |
| 表面物种 | `Surf`, `HSurf`, `NSurf`, `NHSurf`, `NH2Surf` | 相同 | 0 |

在按反应式规范化比较时，Hong 的 422 条反应全部包含于 Shao 的 468 条反应；新增的 46 条均为气相粒子与铁表面物种的吸附、Eley–Rideal 加氢/脱附或 Langmuir–Hinshelwood 路径：

H + Surf => HSurf
