# Shao2024 JACSAu：Windows 本地复现与结果对比

## 复现对象

- 论文：K. Shao and A. Mesbah, *JACS Au* (2024)，DOI: [10.1021/jacsau.3c00654](https://doi.org/10.1021/jacsau.3c00654)。
- 上游实现：[wwwccttoo/DFT-microkinetic](https://github.com/wwwccttoo/DFT-microkinetic)，固定至提交 `54f1bfcf3e211e015f760085e6aa5e1bbc303743`。
- 模型：作者提供的 DFT 修正微观动力学模型（`Const_E` 工况）。

## 复现方法与边界

1. 在每个独立工况目录中复制作者已经生成的 `ZDPlasKin_m.f90`，由本地 Python 调度 Windows 原生 `preprocessor.exe`、`gfortran.exe` 和 `Const_E.exe`；全流程不依赖 Git Bash。
2. 作者的原始反应输入包含超过 Windows 预处理器可安全处理长度的长行，因此本次以作者仓库随附、已生成的 Fortran 机理模块作为权威机理输入，而非重新从原始输入文件生成该模块。
3. 对主程序仅作输出和终止时刻适配：将终止时间设为 4000 s，并在积分结束后强制写出一次结果。没有改动反应机理、反应速率、初始组成或工况参数。
4. 以作者随仓库发布的 `base_*.pkl`、`extract_*.pkl` 为参考；将本地结果插值/取样在相同的 4000 s 时刻比较。

四个工况均使用电子密度 \(8.27\times10^7\ \mathrm{cm^{-3}}\)、氮气摩尔分数 1/3：

| 电场 (V/Å) | 气体温度 (K) | 本地运行用时 (s) |
| ---: | ---: | ---: |
| 0.06 | 350 | 139.50 |
| 0.06 | 550 | 30.22 |
| 0.11 | 350 | 41.47 |
| 0.11 | 550 | 35.28 |

## 4000 s 的 NH3 结果

数值为数密度（cm⁻³）。相对误差定义为 `(本地 DFT 复算 - 作者 DFT) / 作者 DFT`。

| 电场 (V/Å) | 温度 (K) | 作者 base | 作者 DFT | 本地 DFT 复算 | 对 DFT 相对误差 | DFT 相对 base |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.06 | 350 | 1.42742e14 | 9.88775e13 | 9.88770e13 | -0.00055% | -30.73% |
| 0.06 | 550 | 1.69866e17 | 1.41290e17 | 1.41290e17 | 0.00000% | -16.82% |
| 0.11 | 350 | 6.72238e17 | 5.71767e17 | 5.72130e17 | +0.06345% | -14.95% |
| 0.11 | 550 | — | 2.73930e17 | 2.73930e17 | 0.00000% | — |

`0.11 V/Å, 550 K` 的作者 base 参考文件只记录到约 3571 s，故不能在 4000 s 对该工况计算 base–DFT 差异；这不是结果缺失或本地计算失败。

在全部可比较的 DFT 数值中，最大绝对相对误差为 **0.06345%**（0.11 V/Å，350 K 的 NH3）。N2、H2、电子密度和功率的逐点差异也在该量级或更低，说明 Windows 本地构建、运行与结果解析链路可重现作者给出的 DFT 输出。

## 结论

- 本地 DFT 复算曲线/终值与作者 DFT 数据一致；图中的本地复算点与作者 DFT 点重合或近似重合。
- 在前三个可直接比较的 4000 s 工况中，DFT 修正均降低 NH3：约 14.95%–30.73%。因此两组模型的差异主要来自机理中的 DFT 修正，而不是 Windows 平台迁移、编译器或 Python 调度。
- 功率在 base 与 DFT 间基本保持一致；可将 NH3 差异归因于反应网络/表面过程的动力学改变，而非输入功率差异。
